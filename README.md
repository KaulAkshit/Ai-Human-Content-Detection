# Ai-Human-Content-Detection
This project focuses on detecting and analyzing differences between AI-generated and human-written content. It utilizes Python along with key libraries such as Pandas for data manipulation and Matplotlib for data visualization. The analysis examines various linguistic and structural features including sentence length, lexical diversity, and grammatical patterns to identify distinguishing characteristics between the types of writing.
The project is organized into three main phases: Data Reading, Analysis, and Visualization. Each phase is further divided into modules for clarity and user convenience. The program was developed on a Windows system, though it can be executed on any computer supporting Python and the required libraries.
The objective of this project is to understand the evolving capabilities of AI-generated text and to develop analytical methods that can accurately detect and differentiate it from human writing.

The project includes the following features:
1. Analysis of datasets containing AI-generated and human-written text samples
2. Reading and loading data from CSV files for processing
3. Searching and filtering specific records or linguistic attributes
4. Displaying statistical summaries of the dataset using Pandas
5. Visualizing comparative trends and patterns through graphs using Matplotlib
6. Generating concise summary reports highlighting key differences between AI and human writing
